# Welcome to Wartime Diaries

This is a public garden of dispatches, cultural reflections, and memory fragments from the long emergency.

I began journaling privately in 2020. This space is not that journal—it's what I’ve chosen to share from it. Curated, intentional, slow.

Some days are loud. Most are quiet. All deserve witness.
